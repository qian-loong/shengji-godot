# Balance Check: 升级结算系统（三种预设模式）

**Date**: 2026-07-26  
**Analyzed System**: 升级结算（Upgrade Settlement）  
**Scope**: 经典、竞技、快速三种预设模式的升级数值平衡性

---

## Data Sources Analyzed

- `src/godot/scripts/core/rule_config.gd` (lines 233-343) — 三种预设的实现
- `design/gdd/rule-config.md` (§8.1-8.4) — PRD 设计规范
- `design/gdd/upgrade-settlement.md` (C6 升级阶梯) — 标准升级表定义

## Health Summary: **⚠️ CONCERNS**

竞技模式存在**严重设计偏离**，当前实现与 PRD 定义不符。快速模式缺少"换庄不升级"缓冲区。

---

## 关键问题汇总

### 🔴 P0 - 竞技模式完全偏离 PRD

| 规则项 | PRD 定义 | 当前代码 | 偏离程度 |
|--------|---------|---------|---------|
| `deck_count` | **2副牌** | **3副牌** | ❌ 严重 |
| `trump_mode` | **BID（亮主）** | **GRAB（抢主）** | ❌ 严重 |
| `bid_requires_joker` | **false**（级牌可定主） | **true** | ❌ 严重 |
| `no_skip_ranks` | `[5, 10, K]` | `[J, K]` | ⚠️ 中等 |
| 升级表"换庄不升级"区 | 应存在 | **不存在** | ❌ 严重 |

**影响**：
- PRD 设计意图："提高门槛（80→100），保持2副牌标准玩法"
- 当前实现："改成3副牌 + 抢主模式 + 跳过+1级阶段"
- **这是两个完全不同的游戏模式**

---

### 🟡 P1 - 竞技模式升级表缺少"换庄不升级"缓冲区

**当前竞技模式升级表**：
```
[0, 0, 3]     # 庄家0分→升3级
[1, 0, 2]     # 庄家1-49分→升2级
[50, 0, 1]    # 庄家50-99分→升1级
[100, 1, 2]   # 闲家100-149分→升2级 ⚠️ 直接升级，没有缓冲
[150, 1, 3]   # 闲家150+分→升3级
```

**问题**：
1. **破坏核心机制**：经典模式的 80-119 分是"换庄不升级"缓冲区，让攻方先夺权再考虑升级
2. **跳过+1级阶段**：100-149 直接升2级，缺少渐进性
3. **分值体验同质化**：拿100分和拿149分体验完全相同（都是升2级）

**对比经典模式**：
```
[80, 1, 0]    # 闲家80-119分→换庄不升级（缓冲区）
[120, 1, 1]   # 闲家120-159分→升1级
[160, 1, 2]   # 闲家160-199分→升2级
[200, 1, 3]   # 闲家200+分→升3级
```

经典模式有**四档**攻方结果（换庄/+1/+2/+3），竞技只有**两档**（+2/+3）。

---

### 🟡 P2 - 快速模式缺少"换庄不升级"缓冲区

**当前快速模式升级表**：
```
[0, 0, 3]     # 庄家0分→升3级
[1, 0, 2]     # 庄家1-29分→升2级
[30, 0, 1]    # 庄家30-59分→升1级
[60, 1, 1]    # 闲家60-89分→升1级 ⚠️ 直接升级
[90, 1, 2]    # 闲家90-119分→升2级
[120, 1, 3]   # 闲家120+分→升3级
```

**问题**：
- 60 分达到门槛后**直接升级**，没有"换庄不升级"阶段
- 攻方拿到60分就立刻获得双重奖励（换庄+升级），**过于激进**

**影响**：
- 快速模式应该是"简化规则"而非"改变核心机制"
- 移除缓冲区让博弈深度下降（没有"先夺权再冲分"的策略层次）

---

### 🟢 P3 - 经典模式符合 PRD，但 PRD 自身有矛盾

**当前经典模式升级表**：
```
[0, 0, 3]     # 庄家0分→升3级
[1, 0, 2]     # 庄家1-39分→升2级
[40, 0, 1]    # 庄家40-79分→升1级
[80, 1, 0]    # 闲家80-119分→换庄不升级 ✅
[120, 1, 1]   # 闲家120-159分→升1级 ✅
[160, 1, 2]   # 闲家160-199分→升2级 ✅
[200, 1, 3]   # 闲家200+分→升3级 ✅
```

✅ **完全符合 PRD C6 升级阶梯定义**

**但 PRD §8.1 与代码存在矛盾**：

| 项目 | PRD §8.1 | 当前代码 | 备注 |
|------|---------|---------|------|
| `bid_requires_joker` | **true**（必须持有王才能定主） | **false** | 代码宽松 |
| `trump_joker_color_match` | **true**（王的颜色必须与级牌花色匹配） | **false** | 代码宽松 |
| `four_same_is_tractor` | 未明确 | **true** | 代码支持 |

**结论**：当前经典模式比 PRD 更宽松（定主门槛更低），可能是后续迭代决策。

## 升级速度对比分析

### 攻方升级效率（从换庄到升1级所需额外分数）

| 模式 | 换庄门槛 | 升1级所需分数 | 额外分数 | 间隔比例 |
|------|---------|-------------|---------|---------|
| **经典** | 80 | 120 | **+40** | 50% |
| **竞技（当前）** | 100 | 跳过+1级 | **+50跳到+2** | 激进 |
| **竞技（建议）** | 100 | 150 | **+50** | 50% |
| **快速** | 60 | 60（无缓冲） | **0** | 无缓冲 |

### 对局时长预估（2到A所需局数）

假设每局攻方平均拿 120 分（经典模式小胜标准）：

| 模式 | 每局平均升级 | 2→A所需局数 | 预估时长 |
|------|------------|------------|---------|
| **经典** | +1级 | ~12局 | 15分钟 × 12 = **3小时** |
| **竞技（当前）** | +2级（跳过+1） | ~6局 | 20分钟 × 6 = **2小时** |
| **竞技（建议）** | +1级（门槛更高） | ~15局 | 20分钟 × 15 = **5小时** |
| **快速** | +1级（门槛低） | ~8局 | 8分钟 × 8 = **1小时** |

**关键发现**：
- 当前竞技模式**比经典模式更快**（2小时 vs 3小时），与"20-25分钟对局时长"的 PRD 定位矛盾
- 竞技模式如果恢复+1级阶段，对局时长会**显著增加**（5小时），可能过长

## 数值平衡性评估

### 庄家防守奖励对称性

| 模式 | 庄家守住（最低档） | 攻方小胜（最低档） | 对称性 |
|------|------------------|------------------|--------|
| **经典** | 40-79分→+1级 | 120-159分→+1级 | ✅ 对称 |
| **竞技（当前）** | 50-99分→+1级 | ~~100-149分→+2级~~ | ❌ 不对称 |
| **竞技（建议）** | 50-99分→+1级 | 150-199分→+1级 | ⚠️ 攻方难度更高 |
| **快速** | 30-59分→+1级 | 60-89分→+1级 | ✅ 对称 |

**问题**：
- 竞技模式当前设计让攻方100分直接升2级，**奖励过高**
- 建议方案虽然对称，但攻方需要多拿50分（vs 经典的40分）才能升级，**庄家优势过大**

### 风险回报比

以"冒险抠底"为例（攻方出牌阶段 70 分，赌最后一墩拖拉机抠底）：

| 模式 | 底牌10分×4倍 | 最终得分 | 结果 | 是否值得 |
|------|------------|---------|------|---------|
| **经典** | 70 + 40 = 110 | 换庄不升级 | ❌ 不值得（未达120） |
| **竞技（当前）** | 70 + 40 = 110 | 换庄+升2级 | ✅ 大胜（达100） |
| **竞技（建议）** | 70 + 40 = 110 | 换庄不升级 | ❌ 不值得（未达150） |
| **快速** | 70 + 40 = 110 | 换庄+升2级 | ✅ 大胜（达90） |

**结论**：
- 当前竞技模式**过度奖励抠底**（110分直接升2级）
- 建议方案让抠底风险**过高**（需要150分才能开始升级）

## Degenerate Strategies Found

### 策略 1：竞技模式"赌100分"策略

**当前竞技模式下**：
- 攻方只需拿到 100 分即可升2级（跳过+1级）
- 最优策略：**不追求150+分，守住100分即可**
- 副作用：对局缺少"冲刺高分"的激励

**破坏的设计意图**：
- PRD 强调"高手对决，精准配合"
- 但 100 分的低门槛让玩家采取保守策略（够100就行）

### 策略 2：快速模式"60分速胜"策略

**当前快速模式下**：
- 攻方60分立刻换庄+升级（双重奖励）
- 最优策略：**全力冲60分，不管底牌**
- 副作用：抠底机制形同虚设

| 优先级 | 问题 | 建议修复 | 影响 |

## Suggested Upgrade Tables

### 建议的竞技模式升级表（50分间隔 + 缓冲区）

```gdscript
config.upgrade_table = [
    [0, 0, 3],     # 庄家0分→升3级
    [1, 0, 2],     # 庄家1-49分→升2级
    [50, 0, 1],    # 庄家50-99分→升1级
    [100, 1, 0],   # 闲家100-149分→换庄不升级 ✅ 增加缓冲
    [150, 1, 2],   # 闲家150-199分→升2级
    [200, 1, 3]    # 闲家200+分→升3级
]
```

**优点**：
- ✅ 恢复"换庄不升级"核心机制
- ✅ 保持 PRD "100分门槛"的设计意图
- ✅ 仍然比经典更激进（150升2级 vs 经典160升2级）

**缺点**：
- ⚠️ 仍然跳过+1级阶段（无 150-199→+1 档）
- ⚠️ 对局时长可能过长（需实测）

### 建议的快速模式升级表（可选：增加缓冲）

```gdscript
config.upgrade_table = [
    [0, 0, 3],     # 庄家0分→升3级
    [1, 0, 2],     # 庄家1-29分→升2级
    [30, 0, 1],    # 庄家30-59分→升1级
    [60, 1, 0],    # 闲家60-79分→换庄不升级 ✅ 增加缓冲（可选）
    [80, 1, 1],    # 闲家80-109分→升1级
    [110, 1, 2],   # 闲家110-139分→升2级
    [140, 1, 3]    # 闲家140+分→升3级
]
```

**或保持当前设计（不加缓冲）**：
- 快速模式本就是"简化+加速"，直接升级也合理
- 缺点是策略深度下降

## Values That Need Attention

### 1. 竞技模式 `deck_count`

| 当前值 | PRD 值 | 建议 |
|-------|--------|------|
| **3** | **2** | 改为 2（严重偏离） |

**理由**：3副牌（每人38张手牌）完全改变游戏节奏，与 PRD "高手对决2副牌标准玩法"矛盾。

### 2. 竞技模式 `trump_mode`

| 当前值 | PRD 值 | 建议 |
|-------|--------|------|
| **GRAB** | **BID** | 改为 BID |

**理由**：抢主（GRAB）是首局特殊机制，PRD 明确竞技模式应使用亮主（BID）。

### 3. 竞技模式 `bid_requires_joker`

| 当前值 | PRD 值 | 建议 |
|-------|--------|------|
| **true** | **false** | 改为 false |

**理由**：PRD §8.2 强调"级牌可单独定主"是竞技模式核心特色。

### 4. 竞技模式 `upgrade_table` 第4行

| 当前值 | 建议值 | 理由 |
|-------|--------|------|
| `[100, 1, 2]` | `[100, 1, 0]` | 增加"换庄不升级"缓冲区 |

### 5. 快速模式 `upgrade_threshold` vs `upgrade_table` 第4行

| 当前 | 问题 | 建议 |
|------|------|------|
| `threshold=60`, `[60, 1, 1]` | 无缓冲区 | 可选增加 `[60, 1, 0]` |

## Next Steps

1. **P0 修复**：将竞技模式恢复为 PRD 定义（2副牌 + BID + 级牌可定主）
2. **P1 修复**：为竞技模式增加"换庄不升级"缓冲区（`[100, 1, 0]`）
3. **决策点**：竞技模式是否需要+1级阶段？
   - **方案 A**（激进）：保持当前跳过+1级（150→+2, 200→+3）
   - **方案 B**（渐进）：增加+1级（150→+1, 200→+2, 250→+3）
4. **测试验证**：实际对局测试三种模式的升级速度和对局时长
5. **文档同步**：更新 PRD §8.2 或修正代码，确保一致性

## 总结

**当前状态**：
- ✅ 经典模式数值健康，符合 PRD
- ❌ 竞技模式严重偏离 PRD，实现了一个"3副牌抢主高难度"模式，而非"2副牌高门槛标准"模式
- ⚠️ 快速模式缺少缓冲区，但可能是有意简化

**核心建议**：
- **立即修复** P0 问题（竞技模式基础配置）
- **认真考虑** P1 问题（是否需要"换庄不升级"缓冲区）
- **长期评估** 升级速度是否需要实测调优
