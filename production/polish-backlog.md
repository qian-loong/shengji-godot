## UX-P01 — 每墩浮动/日志刷屏

**状态**: 确认存在 · 待做  
**现象**: 每墩出牌、赢墩都会写 UI 日志 / 消息区，信息噪声大。  
**代码依据**:
- `gui_game.gd` 每人出牌 `_log("  %s 出: %s")`
- 墩结束 `_log("  → %s 赢墩…")` + `_set_message("%s 赢墩 | +%d 分…")`
**方向**:
- 出牌阶段默认不刷逐出日志；仅保留关键节点（亮主/配底/结算）
- 或提供「详细日志」开关（可复用 `DebugConfig`）

## UX-P03 — 出牌瞬间界面扰动 / 跳动

**状态**: 确认存在（机制上可复现） · 待做  
**现象**: 选中后点「出牌」，出牌区/手牌区有变大再变小的视觉跳动。  
**代码依据**:
- 选中上浮：`hand_display` 选中 `y -= rise`，`clip_contents = true`
- 选中描边：`card_view._draw_selection_border` 外扩 1px 绿框
- 出牌瞬间：清空选中 + 手牌 relayout + 牌从手牌消失进桌面槽
**可能根因（待验证）**:
1. 选中绿框/上浮区域盖在绿色牌桌边缘，出牌后消失造成「桌面闪一下」
2. 手牌高度预算含 rise，出牌后张数变化导致 spacing 重算，整排手牌横向/纵向重排
3. 出牌槽位从空到有牌，中心区布局跳变（非 tween）
**方向**:
- 出牌动画：先 tween 到手牌→桌面，再清选中
- 选中态不依赖会盖住桌面的外扩描边；或固定手牌区背景遮罩
- 固定手牌布局高度，减少张数变化引起的 reflow

## UX-P05 — 主界面「开始对局 / 自定义规则」信息架构

**状态**: 产品决策 · 待评审  
**现象**: 主菜单两个入口，用户感觉「规则预设」路径多余。  
**现状**:
- `开始对局` → `preset_selector`（经典/竞技/快速，卡内再有「自定义规则」）
- `自定义规则` → 直接 `room_config`（无先选预设时默认经典底）
**分析**:
- 功能上不重复：一个是选预设开打，一个是直接改规则
- 体验上易冗余：预设页卡内已有「自定义规则」，主菜单再放一个「自定义规则」叠床架屋
**方向（任选）**:
- A. 主菜单只留「开始对局」；自定义只放在预设卡内  
- B. 主菜单「开始对局」直接进默认预设，高级设置进二级  
- C. 保留双入口但改文案（如「快速开局 / 规则工坊」）降低混淆
